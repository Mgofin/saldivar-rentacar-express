# saldivar-rentacar-express

# RentaCar Express es un programa que ayuda a automatizar el proceso de alquiler de vehículos realizando cálculos automáticos de tarifas, descuentos corporativos, cargos adicionales e impuestos, mostrando al usuario el total final a pagar de forma clara y precisa.
